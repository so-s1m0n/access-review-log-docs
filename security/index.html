Security and data handling

Access Review Log requests read access to Jira project details and project permission schemes, plus app-scoped Forge storage. Jira checks every request using the current user's permissions.

Review history is stored in Atlassian-hosted Forge storage for up to 365 days, with a maximum of 100 records per project. Records contain configured grant snapshots, decision, reviewer account ID, timestamp, project metadata and optional note. Project admins can delete project history.

No external backend, analytics SDK, or configured data egress. The app is read-only toward Jira. It displays configured grants and does not calculate each person's effective access.

Launch status: live authorization, uninstall deletion, tenant isolation, and license tests have not yet run on a Forge development installation. This page must be reconciled with Marketplace security answers before publication.
