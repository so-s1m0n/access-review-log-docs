Setup and usage

Pre-launch draft: Forge app registration and live installation are pending.

  1. Install Access Review Log from your Jira site's app management page.
  2. Open a Jira project and select Access Review Log in project settings.
  3. Select Load access details; Jira checks access as your current user.
  4. Review configured permission grants. Groups and roles are not expanded to individual users.
  5. Choose a decision, add an optional note, and save the timestamped record.
  6. Export or delete review history from the same project page.

The app does not change Jira settings or compute effective access.
